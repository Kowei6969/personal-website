LED Control System

An embedded systems project exploring binary logic and PWM control on a microcontroller. Features include a "breathing" LED effect using PWM-based brightness fading, and a custom "Chase the Knight" animation — a Knight Rider–style LED chase using bitwise shifting logic. Both effects include adjustable speed and brightness, controlled in real time. Built to demonstrate core digital I/O, bit manipulation, and PWM techniques in C++.
